## 1. AI tools used to build the solution / 开发过程中使用的 AI 工具

其他成员若在自己负责的部分使用了其他 AI 助手，请在提交前补充到上表。

## 2. AI models inside the solution / 方案内部使用的 AI 模型

| Model | Where it runs | Role |
|---|---|---|
| `qwen2.5-coder:3b` via **Ollama** | Locally, on the developer's machine | Proposes PySpark for jobs outside the deterministic rule path (MERGE, stored procedures, SAS), with at most 3 repair attempts driven by shrunk synthetic counterexamples. |

- The model receives legacy code, table schemas and synthetic rows only.
- Its output is never trusted: it must pass a static safety check and the same reconciliation as rule-generated code.
- As of this submission **no AI-translated job has passed reconciliation** (Tested = 0); the 7 Verified jobs were produced by the deterministic rule path without any model call.

## 3. Existing code and libraries / 既有代码与开源库

No pre-existing project code was reused; the repository was written during the hackathon.
Open-source libraries (see `requirements.txt`): PySpark, Delta Lake (`delta-spark`), sqlglot, pandas, PyArrow, Streamlit, PyYAML, pyodbc, pytest.

## 4. Data / 数据

Public dataset **freMTPL2** (`freMTPL2freq`, `freMTPL2sev`) plus synthetic rows generated by the engine. No client or personal data.
